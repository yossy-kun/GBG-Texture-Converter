### このツールについて
このツールは、画像を「はじめてゲームプログラミング」仕様のドット絵（テクスチャ）に変換するツールです。<br>
好きな画像をアップロードするだけで、簡単にはじプロ風のドット絵を作成できます。<br>
変換したドット絵は、画像として保存したり、自動描画ツールを使ってはじプロのゲーム内に取り込んだりできます。<br>
画像はすべてブラウザ内で処理され、外部に送信されることはありません。
### 使い方
1. 変換したい画像をアップロード
2. ドット絵の大きさや色合いなどの調整
3. 変換したドット絵をダウンロード(画像として保存するならPNG、自動描画用のテクスチャデータとして保存するならCSV)
